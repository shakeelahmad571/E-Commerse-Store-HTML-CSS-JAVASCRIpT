# 🛍️ TechGadgets — E-Commerce Website

A modern, responsive e-commerce website for exploring and shopping for the latest tech gadgets and electronics. Built with HTML, CSS, and JavaScript to practice real-world frontend development.

## 🚀 Features

- 🏠 **Responsive Homepage** — Modern landing page with featured products and categories.
- 🛒 **Shopping Cart** — Add and remove products, update quantities, and calculate subtotal, tax, and total price.
- 🔍 **Product Search** — Search products by name.
- 🎯 **Product Filtering** — Filter products by category, brand, and price.
- ↕️ **Product Sorting** — Sort products by price from low to high or high to low.
- 📄 **Pagination** — Browse products across multiple pages.
- 🌙 **Dark & Light Mode** — Switch between themes for a comfortable browsing experience.
- 📱 **Responsive Design** — Designed for desktop, tablet, and mobile screens.
- 💾 **Local Storage** — Preserve cart data across page reloads.
- 🌐 **API Integration** — Fetch product data dynamically from an external API.

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, Flexbox, Grid, and responsive layouts
- **JavaScript (ES6+)** — Dynamic functionality and DOM manipulation
- **REST API** — Fetching product data
- **Local Storage** — Client-side data persistence
- **Font Awesome / SVG Icons** — Interface icons

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Open the project

Navigate to the project folder:

```bash
cd TechGadgets
```

### 3. Run the website

Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

No build tools are required for the basic frontend setup.

## 🌐 API Integration

Product data is fetched dynamically from the [DummyJSON Products API](https://dummyjson.com/products).

The API provides sample product information for practicing data fetching, rendering product cards, and implementing search, filtering, sorting, and pagination.
